# Security Policy / 安全策略

## Supported version / 支持的版本

The latest release tag is supported. / 仅支持最新的 Release 版本。

## Reporting a vulnerability / 报告漏洞

Please do **not** open a public issue for security problems.

- On GitHub: use "Report a vulnerability" (Security → Advisories) 私密报告
- On Gitee: 私信仓库所有者 / send a private message to the repo owner

Include: affected version, reproduction steps, impact. We will respond within
7 days. / 请附影响版本、复现步骤与影响面，7 日内答复。

## Scope note / 范围说明

This app is fully offline and holds no secrets. Firmware runs on a
user-programmable MCU — flashing custom firmware is an intended capability,
not a vulnerability.
